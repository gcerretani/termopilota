Istruzioni setup Google OAuth (una volta sola)
  1. Vai su Google Cloud Console → Credentials
  2. Crea un OAuth client ID di tipo Web application
  3. Aggiungi la redirect URI mostrata qui sopra fra le "Authorized redirect URIs"
  4. Copia Client ID e Client Secret nei campi sopra, salva, poi riavvia l'app
  5. Gli utenti che vorrai far accedere via Google devono essere creati qui (in Utenti) con la stessa email del loro account Google
